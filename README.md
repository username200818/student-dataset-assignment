# Assignment Two: Fictional Student Dataset

## Description
This project contains a fictional dataset of 15 students. It includes:
1. Student ID
2. Department
3. Level
4. Attendance Percentage
5. Average Examination Score

All student records and scores are fictional and are provided for this assignment.

## Files
- `main.py` — Python program that creates the dataset and saves it as a CSV file.
- `students.csv` — The generated dataset.

## How to run
1. Make sure Python 3 is installed.
2. Open a terminal in this project folder.
3. Run: `python main.py`
4. The program creates (or replaces) `students.csv`.
